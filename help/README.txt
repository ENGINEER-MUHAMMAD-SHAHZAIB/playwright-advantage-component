=====================================================
 HELP FOLDER - WHICH FILE TO OPEN
=====================================================

commands.txt
   All terminal commands, run steps, logs, and speed settings (with line numbers).
   Open this most of the time.

NEW_PROGRAM_GUIDE.txt
   What to do when you get a NEW guide / program / school
   (convert_guide.py -> check Excel -> set add_components.py -> run).

Advantage_Automation_Run_Guide.pdf
   Full run guide: files, .env, Excel columns, settings, run plan, logs, errors, fixes.
   Note: the script changed after this PDF was made (grid-only flow, duplicate
   protection, speed settings). For exact line numbers use commands.txt.

Advantage_SIS_Automation_Setup_Guide.pdf
   First-time laptop setup: Python, VS Code, Playwright, recording.
   Only needed on a new laptop.

-----------------------------------------------------
Open a file from the project folder:
   code help\commands.txt
   code help\NEW_PROGRAM_GUIDE.txt
   start help\Advantage_Automation_Run_Guide.pdf
